# ByteFix — Página web empresarial (demostración)

Página web de una sola página para **ByteFix**, un taller ficticio de reparación y mantenimiento de cómputo en San Mateo Tlacoxcalco, Puebla. Es un proyecto escolar de la materia *Aplicaciones Web* (actividad en equipo 2.3, «Configuración de un agente para una página empresarial»).

> **Aviso:** ByteFix es una empresa ficticia. Sus datos, precios e imágenes son ilustrativos. En esta copia publicada el número de contacto está **desactivado**: los botones abren WhatsApp con el mensaje listo, pero sin destinatario.

## Tecnologías

- HTML5, CSS3 y JavaScript *vanilla*
- Bootstrap 5.3.8 (jsDelivr, con SRI) y Bootstrap Icons 1.13.1 (SVG en línea)
- Tipografías Baloo 2 y Atkinson Hyperlegible (Google Fonts)
